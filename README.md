# مولّد ترميز الوثائق وتعبئة الفورم

تطبيق ويب (ملف `index.html` واحد) يولّد ترميز ملفات الجودة بالصيغة:

`P2S4D1a1-252026`

- `P2` القسم، `S4` المعيار، `D1` الفقرة
- `a` المؤشر (1 = a، 2 = b)، و`1` رقم النقطة داخل المؤشر
- `25` عدد النقاط الكلي، `2026` السنة

يرفع المستخدم كل الصور دفعة واحدة، فتُرتَّب حسب اسم الملف ويأخذ كل ملف ترميزه (a1، a2، ...)،
ثم تُوضع الصورة داخل فورم الوثيقة ويُكتب الترميز بجانب «الرمز:» ويُحفظ PNG أو PDF.

التشغيل: افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع.
